## 更新内容

- 新增简体中文 / English 界面切换，入口位于「设置 → 语言」。首次使用匹配系统语言，手动选择会保存在本机。
- 为待办、每日笔记、归档、剪贴板、外观设置、QQ / 微信消息、QQ 邮箱和快捷翻译面板接入翻译字典。
- 语言选择同步到独立翻译窗口，切换语言时保留正在输入的原文以及已有任务、笔记和自定义预设。
- 修正西里尔文、希腊文等文字的宽度估算，改善多语言任务标题的折叠宽度和换行表现。
- 完善语言代码校验，并修复英文外观按钮文字被截断的问题。

## What's New

- Added Simplified Chinese / English interface switching under **Settings → Language**. The first launch matches the system language, and an explicit choice is saved locally.
- Localized task, daily note, archive, clipboard, appearance, QQ / WeChat message, QQ Mail, and quick translation panels with typed dictionaries.
- Synced the language preference with the separate translation window while preserving source text, tasks, notes, and custom presets.
- Fixed text width estimates for Cyrillic, Greek, and other narrow scripts, improving collapsed island sizing and task title wrapping.
- Added locale validation and fixed truncated English appearance labels.
