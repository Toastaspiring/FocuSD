## 更新内容

- 没有已开始的任务时，折叠岛屿默认显示“剩余 x 个待办”，只统计当前未完成任务；开始任务后显示任务标题，完成后恢复数量。

- 翻译面板新增实时字数、清空原文和译文、处理中状态与“已复制”反馈，改善最小窗口下的布局与焦点显示。
- 保留 Tab 粘贴、Enter 翻译、全局快捷键和密钥设置；清空正在翻译的内容后，迟到的结果不会重新显示。

## What's New

- The collapsed island now shows the remaining unfinished todo count when no task has been started. Starting a task shows its title; completing it restores the count.
- Added **Settings → Layout → Show todo count when idle**, with a saved preference. The existing collapsed-text switch still controls all collapsed text.
- Refined the translation panel to match the website preview, with a charcoal surface, a clear language direction bar, and mint translation text. Wider windows support side-by-side reading.
- Added a live character count, clear action, loading status, and copied feedback, with improved layout and focus indicators at the minimum window size.
- Preserved Tab to paste, Enter to translate, the global shortcut, and key settings. Clearing an in-progress translation also prevents late results from reappearing.

## Downloads

- `fly-island_0.2.7_x64_en-US.msi`: Windows x64 MSI installer.
- `SHA256SUMS.txt`: SHA-256 checksums for both installers.
