# Fusion Pixel

The pixel font option bundles the unmodified simplified Chinese, 12px proportional
WOFF2 from [Fusion Pixel Font 2026.10.16](https://github.com/TakWolf/fusion-pixel-font/releases/tag/2026.10.16).
It loads locally and requires no external font service.

The font is licensed under SIL Open Font License 1.1. See `OFL-Fusion-Pixel.txt`
and the upstream notices in `LICENSES/`, copied from the official release archive.
